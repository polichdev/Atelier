# audio

Directory: [`crates/audio`](../../crates/audio/) · Cargo package: `atelier-audio`

`capture.rs` starts a WASAPI loopback capture thread, `fft.rs` computes spectrum data, and `visualizer.rs` derives pulse state. `AudioManager` owns capture and exposes spectrum and tint operations. The Audio tab controls a separate desktop visualizer with bars, wave, dots, circle and symmetric wave styles. It supports presets, gradients, glow, adjustable bar count and thickness, and transparent backgrounds. Optional silence hiding keeps monitoring audio so the widget returns when sound resumes. Optional fullscreen pause suspends visualizer polling until fullscreen ends. The desktop visualizer, optional wallpaper pulse/glow effects and desktop dock glow share a single loopback capture. Dock reactivity is configured in the Audio tab and applies when the separate desktop dock is enabled and visible. It supports glow color and intensity, optional breathing and corner deformation, frequency selection, sensitivity and smoothing. Capture starts when a consumer requests data and stops after a short idle period when none needs it. The visualizer analyzes the default output locally; it does not use the microphone. It reconnects after output-device changes, and reports an unavailable device in the widget. Visualizer settings are stored with other widgets; dock and wallpaper effect settings are stored with their respective configurations. See the [Audio reactivity guide](../AUDIO_REACTIVITY.md).
