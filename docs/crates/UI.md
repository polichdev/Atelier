# ui

Directory: [`crates/ui`](../../crates/ui/) · Cargo package: `atelier-ui`

`atelier-ui` is the Tauri Studio. `src/main.rs` dispatches helper and test modes; `src/lib.rs` configures state, IPC, tray and window lifecycle. `ui/index.html` is the Studio; `studio-dock.js` manages its dock controls. `ui/dock.html` and `dock.js` implement the separate dock window.

`src/desktop_dock.rs` manages dock settings, pinned shortcuts, application/window enumeration, icons, placement, launch and activation. When enabled, the dock hides Explorer's taskbars after starting recovery helpers. The dock is hidden while a fullscreen application or fullscreen game is active on its monitor, and returns when that application loses focus or exits fullscreen; audio-reactive dock effects stop while it is hidden. The dock includes optional Start and Search buttons, a launch-animation switch, an option to open compatible windows maximized, and per-app visibility controls. A bottom-gap slider reserves space on the selected display using a temporary Windows appbar; zero removes the reservation. Hidden apps can be restored from the Studio list. Icon extraction requests higher-resolution shell icons where available. Windows applications can still control their own window size or provide only low-resolution icons. Network and volume open Quick Settings, and the clock opens notifications and calendar. The language and hidden-icons buttons attempt to invoke Explorer's native controls through Windows UI Automation without revealing the taskbar; availability depends on the Windows version and shell accessibility provider. The Tauri configuration declares main and dock window capabilities and requests a Mica Studio backdrop.

The Wallpapers tab manages local video and scene imports, desktop playback, global performance settings and items already downloaded through Steam Workshop. `desktop_wallpaper.rs`, `steam_workshop.rs`, `wallpaper_scene.rs` and the `studio-wallpaper*.js` frontend implement these flows. Video playback holds a recent frame while seeking back to the start of a loop, fades it into the new frame and ignores interrupted play requests that do not indicate a media failure. The per-wallpaper fullscreen pause also pauses for maximized windows when the global fullscreen policy is inherited or set to pause and the maximized policy is the default; explicit application rules and other global policies take precedence. After dock work-area changes, wallpaper attachment is refreshed once changes settle; periodic repair also restores the background layer order if Explorer moves it above the wallpaper. The Widgets tab uses `desktop_widgets.rs` and `studio-widgets.js` to configure desktop widgets. The Audio tab configures a separate desktop spectrum widget and optional audio-reactive dock glow backed by `atelier-audio`.

State files and override variables are listed in [Configuration](../CONFIGURATION.md). Unit, browser and native fixture tests are described in [Development](../DEVELOPMENT.md).
