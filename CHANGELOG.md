# Changelog

Notable changes are recorded here. Entries describe the current development tree; they do not imply a published release.

## Unreleased

- Added Studio controls for Windows taskbar appearance and presets.
- Added a separate macOS-style taskbar with pinned apps, visibility and order controls, custom icons, fullscreen hiding, a maximized-window gap and recovery for hidden Windows taskbars.
- Added a Windows 11 XAML bridge and recovery paths for taskbar appearance and positioning.
- Added Studio window styling, packaging assets and development/test scripts.
- Added local MP4/WebM and partial 2D scene playback, per-wallpaper and global playback controls, and import of supported Workshop items already downloaded by Steam.
- Added desktop widgets and a system-audio visualizer, plus optional audio-reactive wallpaper and dock effects.
- Added local audio loopback capture and recovery for the desktop background. Native tray/language flyouts and scene compatibility remain limited; see the guides for details.
